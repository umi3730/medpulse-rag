# 安装与使用指南

## 1. 环境要求

| 依赖 | 版本要求 |
|------|----------|
| Python | >= 3.8 |
| Neo4j | >= 4.0（推荐 5.x Community） |
| pip | 最新版 |

## 2. 安装步骤

### 2.1 克隆项目

```bash
git clone https://github.com/davis-you/MedicalGraphRAGSystem.git
cd MedicalGraphRAGSystem
```

### 2.2 安装 Python 依赖

```bash
pip3 install -r requirements.txt
```

依赖说明：

| 包名 | 用途 |
|------|------|
| requests | 爬虫 HTTP 请求 |
| lxml | HTML 解析（XPath） |
| langchain-core | LangChain 核心框架 |
| langchain-ollama | Ollama 本地模型集成（并发症分词） |
| py2neo | Neo4j 图数据库操作 |
| pyahocorasick | 问句分类（AC 自动机匹配） |

**Ollama 本地模型（可选，用于并发症智能分词）：**

```bash
# 安装 Ollama: https://ollama.com
# 拉取模型
ollama pull qwen3:8b
# 确保 Ollama 服务在运行
ollama serve
```

> 如果 Ollama 不可用，爬虫会自动降级为简单分隔符切分，不影响运行。

### 2.3 部署 Neo4j 数据库

**方式一：Docker 部署（推荐）**

```bash
docker run -d \
  --name neo4j \
  --restart unless-stopped \
  -p 7474:7474 \
  -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/your_password \
  -e NEO4J_PLUGINS='["apoc"]' \
  -v neo4j-data:/data \
  -v neo4j-logs:/logs \
  neo4j:5-community
```

**方式二：本地安装**

从 [Neo4j 官网](https://neo4j.com/download/) 下载安装，启动后访问 `http://localhost:7474` 设置密码。

### 2.4 配置 Neo4j 连接

编辑 `build_medicalgraph.py`，修改连接信息：

```python
self.g = Graph(
    host="127.0.0.1",
    http_port=7474,
    user="neo4j",         # 你的用户名
    password="your_password"  # 你的密码
)
```

## 3. 使用流程

整个项目分三步：**爬取数据 → 构建图谱 → 启动问答**。

### 3.1 爬取数据

项目已附带预爬好的 `data/medical.json`（8800+ 条疾病记录），可直接跳到 3.2。

如需重新爬取：

```bash
# 爬取全部数据（约 12-15 小时）
python3 data_spider/data_spider.py

# 小范围测试
python3 data_spider/data_spider.py --start 1 --end 10 --test

# 指定范围爬取
python3 data_spider/data_spider.py --start 1 --end 500

# 中断后恢复
python3 data_spider/data_spider.py --resume
```

爬虫参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--start` | 1 | 起始页码 |
| `--end` | 11000 | 结束页码 |
| `--output` | `data/medical.json` | 输出路径 |
| `--resume` | - | 断点续爬 |
| `--delay` | 0.3 | 请求间隔（秒） |
| `--test` | - | 测试模式，只打印不写文件 |
| `--ollama-model` | `qwen3:8b` | Ollama 模型名称 |
| `--ollama-url` | `http://localhost:11434` | Ollama 服务地址 |

### 3.2 导入知识图谱

确保 Neo4j 已启动且连接配置正确，执行：

```bash
python3 build_medicalgraph.py
```

导入过程较长（约 1-2 小时），包含：
- 7 类实体节点（疾病、药品、食物、检查项、科室、药企、症状）
- 11 类实体关系（约 30 万条）

### 3.3 启动问答系统

```bash
python3 chatbot_graph.py
```

输入疾病相关问题即可获得回答，支持 18 类问句：

| 问句类型 | 示例 |
|----------|------|
| 疾病症状 | 乳腺癌的症状有哪些？ |
| 症状找病 | 最近老流鼻涕怎么办？ |
| 疾病病因 | 为什么有的人会失眠？ |
| 疾病忌口 | 失眠的人不要吃啥？ |
| 疾病宜食 | 耳鸣了吃点啥？ |
| 疾病用药 | 肝病要吃啥药？ |
| 药品治病 | 板蓝根颗粒能治啥病？ |
| 疾病检查 | 脑膜炎怎么才能查出来？ |
| 疾病预防 | 怎样才能预防肾虚？ |
| 治疗周期 | 感冒要多久才能好？ |
| 治疗方式 | 高血压要怎么治？ |
| 治愈概率 | 白血病能治好吗？ |
| 易感人群 | 什么人容易得高血压？ |
| 疾病描述 | 糖尿病 |

输入 `q` 退出。

## 5. 常见问题

**Q: 爬虫报错 `ConnectionError`**
A: 网站有频率限制，增大延迟：`--delay 1.0`。

**Q: Neo4j 连接失败**
A: 检查 Neo4j 是否启动（`http://localhost:7474`），确认用户名密码配置正确。

**Q: 导入图谱太慢**
A: 正常现象，4.4 万实体 + 30 万关系需要 1-2 小时。

**Q: `pyahocorasick` 安装失败**
A: 需要 C 编译器。macOS 执行 `xcode-select --install`，Linux 执行 `apt install build-essential`。

**Q: 爬虫中断了怎么办**
A: 使用 `python3 data_spider/data_spider.py --resume` 从断点继续。
